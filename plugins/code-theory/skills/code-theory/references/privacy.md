# Privacy

## Minimisation

GDPR Art. 5(1)(c) data minimisation: personal data goes only where it is needed. Every external host the code talks to should be a deliberate choice, and for each new host you should be able to say what data it receives.

## Confidentiality

GDPR Art. 5(1)(f) integrity and confidentiality. Sensitive data (CVs, salaries, health, private journals) goes to an outside service, an AI model included, only on terms that fit it, such as zero data retention, or not at all.

## By design

GDPR Art. 25 data protection by design: personal data is not printed, logged, or delivered beyond what the recipient needs. Read every print, log and message line in the change.

## Retention

GDPR Art. 5(1)(e) storage limitation and Art. 17 erasure: newly stored personal data has a bound (rotation, a time window, one row per period) or a deletion path.
